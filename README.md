# 핑크의 통화

단편 시나리오 웹북 리더 초고. [GitHub Pages에서 읽기](https://bluehhhh-byte.github.io/pink-on-the-line/).

## 원고

`ch01.md`부터 `ch05.md`까지가 장별 정본이고, `epilogue.md`가 마지막 통화 원고다. 원고 수정 뒤 `py -3 tools/build_novel.py`를 실행하면 `novel.md`, `novel-data.js`, `핑크의 통화.md`가 다시 만들어진다.

장 순서: 나를 돌아봐 → 우리는 → 사랑, 두려움 → 다투고 난 뒤 → 굴레를 벗어나.

## 리더

『나란히 — 예보에 없던 사람』의 공개 리더 엔진을 독립 복사해 만들었다. 원작 원고·장면 이미지·오디오 파일은 포함하지 않았다. 진행 상태와 책갈피에는 이 작품만의 저장 키를 사용한다.

현재 장면 이미지는 연결하지 않았다. 오디오북도 만들지 않았다. 리더의 낭독 버튼은 기기에서 지원하는 웹 음성으로 대체된다.

GitHub Pages는 `main` 브랜치의 저장소 루트에서 배포한다. 서재 「습작들」에는 초고 검토가 끝난 뒤 최종본만 등록한다.
